# Word pair learning task

## Learning phase

Participants are presented with **12 word pairs** for 5 seconds.

## Testing phase

Participants see one of the words from the pair and are asked to type the corresponding word.
If they don't remember, they respond "I don't remember"."

After each response, participants rate their **confidence** on a scale from 0 to 100.


## Files

The trial descriptions and experimental logic can be inspected in `index.html`.
